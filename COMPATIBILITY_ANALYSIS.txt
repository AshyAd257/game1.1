🔍 独特功能分析
========================================

你们的木偶编辑器确实有一些**独创的功能**，这些在标准格式中很难找到：

### 1. 多方向贴图系统 ⭐独创⭐

**你们的实现：**
```json
{
  "directionTextures": {
    "FRONT": "textures/front.png",
    "BACK": "textures/back.png",
    "LEFT": "textures/left.png",
    "RIGHT": "textures/right.png",
    "FRONT_LEFT": "textures/front_left.png",
    ...
  }
}
```

**标准格式的支持：**
- ❌ DragonBones: 不支持
- ❌ Spine: 不支持
- ❌ Blender: 没有直接对应概念
- ⚠️ Unity/Unreal: 需要自定义脚本

### 2. Billboard模式 ⭐独特实现⭐

**你们的实现：**
- 每个部件独立控制2D/3D
- 统一Billboard模式
- 独立Billboard模式
- 面始终朝向相机

**标准格式的支持：**
- ⚠️ Blender: 有Billboard约束，但实现不同
- ⚠️ Unity: 有Billboard组件，但需要适配
- ⚠️ Unreal: 有Sprite系统，但概念不同

### 3. 方向相关属性

**你们的实现：**
```json
{
  "directionPriorities": { "FRONT": 10, "BACK": 5 },
  "directionWidths": { "FRONT": 2.0, "BACK": 1.8 },
  "directionHeights": { "FRONT": 2.0, "BACK": 1.8 },
  "directionOffsets": { "FRONT": {...}, "BACK": {...} },
  "directionRotations": { "FRONT": {...}, "BACK": {...} }
}
```

**标准格式的支持：**
- ❌ 所有标准格式都不支持

### 方案2：编写Blender插件（完整支持）

**需要实现：**

```python
# Blender插件伪代码
class PuppetImporter(bpy.types.Operator):
    def execute(self, context):
        # 1. 读取.puppet或.ppkg文件
        puppet_data = load_puppet_file(filepath)

        # 2. 创建骨架
        armature = create_armature(puppet_data.bones)

        # 3. 处理多方向贴图
        for bone in puppet_data.bones:
            if bone.has_direction_textures:
                # 创建材质切换系统
                setup_direction_materials(bone)

                # 创建驱动器根据相机角度切换材质
                setup_camera_angle_driver(bone)

        # 4. 处理Billboard
        for bone in puppet_data.bones:
            if bone.billboard_enabled:
                # 添加Track To约束
                add_billboard_constraint(bone)

        # 5. 导入动画
        import_animations(puppet_data.animations)

        return {'FINISHED'}
```

**需要实现的功能：**

1. **文件解析**
   - 读取JSON配置
   - 解压.ppkg文件
   - 加载纹理

2. **骨架创建**
   - 创建Armature
   - 设置骨骼层级
   - 应用变换

3. **多方向贴图系统**
   - 为每个方向创建材质
   - 根据相机角度自动切换
   - 使用Geometry Nodes或驱动器

4. **Billboard实现**
   - 添加Track To约束
   - 或使用Geometry Nodes
   - 保持面向相机

5. **方向属性**
   - 根据方向调整尺寸
   - 根据方向调整偏移
   - 根据方向调整优先级（Z-order）

### 方案3：运行时适配（游戏引擎）

**Unity示例：**

```csharp
public class PuppetRenderer : MonoBehaviour {
    private PuppetData puppetData;
    private Camera mainCamera;

    void Update() {
        // 计算相机方向
        Vector3 cameraDir = GetCameraDirection();
        Direction currentDir = GetDirectionFromAngle(cameraDir);

        // 切换贴图
        foreach (var part in puppetData.parts) {
            if (part.directionTextures.ContainsKey(currentDir)) {
                part.spriteRenderer.sprite =
                    part.directionTextures[currentDir];

                // 应用方向相关属性
                part.transform.localScale =
                    part.directionSizes[currentDir];
                part.sortingOrder =
                    part.directionPriorities[currentDir];
            }
        }

        // Billboard
        if (part.billboardEnabled) {
            transform.LookAt(mainCamera.transform);
        }
    }
}
```
