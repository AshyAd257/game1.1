🔧 问题修复
========================================

**问题：**
之前的实现会破坏旧的 .puppet 文件！

**原因：**
- 旧版：.puppet = JSON格式
- 新版：.puppet = ZIP格式
- 结果：旧文件无法打开 ❌

**解决方案：**
使用新的文件扩展名区分两种格式

========================================
📁 新的文件格式定义
========================================

1. **.puppet** - Puppet JSON文件
   - 纯JSON配置文件
   - 向后兼容旧版本 ✅
   - 需要单独管理图片
   - 适合开发使用

2. **.ppkg** - Puppet打包文件 ⭐新格式⭐
   - ZIP格式，包含配置和图片
   - 完全独立，方便分享
   - 自动管理所有资源
   - 适合发布和分享

3. **.json** - 纯JSON格式
   - 标准JSON文件
   - 与 .puppet 格式相同
   - 通用格式

========================================
✅ 兼容性保证
========================================

✓ 旧的 .puppet 文件可以正常打开
✓ 新的 .ppkg 文件包含所有资源
✓ 两种格式可以共存
✓ 不会丢失任何数据

========================================
🚀 使用指南
========================================

### 保存文件

**选项1：Puppet文件 (JSON)** - .puppet
- 仅保存配置
- 兼容旧版本
- 文件小

**选项2：Puppet打包文件 (含图片)** - .ppkg ⭐推荐⭐
- 包含所有资源
- 方便分享
- 完全独立

**选项3：纯JSON格式** - .json
- 标准JSON
- 通用格式

### 加载文件

编辑器自动识别三种格式：
- .puppet → 作为JSON加载
- .ppkg → 作为打包文件加载
- .json → 作为JSON加载

========================================
📊 格式对比
========================================

| 特性 | .puppet | .ppkg | .json |
|------|---------|-------|-------|
| 格式 | JSON | ZIP | JSON |
| 包含图片 | ❌ | ✅ | ❌ |
| 文件大小 | 小 | 中 | 小 |
| 兼容旧版 | ✅ | ❌ | ✅ |
| 适合分享 | ❌ | ✅ | ❌ |
| 推荐用途 | 开发 | 发布 | 通用 |

========================================
🔄 迁移指南
========================================

### 如果你有旧的 .puppet 文件

**不需要做任何事！** ✅
- 旧文件可以直接打开
- 继续使用没有问题

### 如果你想使用新的打包格式

1. 打开旧的 .puppet 文件
2. 另存为 → 选择 "Puppet打包文件 (含图片)"
3. 保存为 .ppkg 文件
4. 完成！

========================================
💡 最佳实践
========================================

**开发阶段：**
```
使用 .puppet 或 .json
- 便于版本控制
- 文件小，加载快
- 图片单独管理
```

**发布/分享：**
```
使用 .ppkg
- 一个文件包含所有内容
- 方便分享给他人
- 不用担心图片路径问题
```

**示例工作流：**
```
1. 开发：保存为 character.puppet
2. 测试：继续使用 character.puppet
3. 发布：导出为 character.ppkg
4. 分享：发送 character.ppkg 给朋友
```

========================================
⚠️ 注意事项
========================================

1. **不要混淆扩展名**
   - .puppet = JSON格式
   - .ppkg = 打包格式
   - 不能互换！

2. **旧文件保持原样**
   - 不需要重命名
   - 不需要转换
   - 直接使用即可

3. **新项目推荐**
   - 开发用 .puppet
   - 发布用 .ppkg
