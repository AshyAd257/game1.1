🎉 新功能：包含图片的打包格式
========================================

现在木偶编辑器支持三种保存格式：

1. **Puppet文件 (*.puppet)** - JSON配置
   - 只保存骨骼结构和配置
   - 纹理路径为绝对路径或相对路径
   - 文件小，但需要单独管理图片文件
   - 向后兼容旧版本 ✅
   - 适合开发过程中使用

2. **Puppet打包文件 (*.ppkg)** - 含图片 ⭐新增⭐
   - 将配置和所有纹理图片打包成一个文件
   - 完全独立，包含所有资源
   - 方便分享和移植
   - 标准ZIP格式，可以手动解压查看
   - 自动压缩，节省空间
   - 适合发布和分享

3. **纯JSON格式 (*.json)** - 标准JSON
   - 与 .puppet 格式相同
   - 通用格式

========================================
📦 打包文件结构
========================================

character.ppkg (实际上是ZIP文件)
├── puppet.json          # 木偶配置
└── textures/            # 纹理文件夹
    ├── texture_0.png
    ├── texture_1.png
    └── ...

========================================
🚀 使用方法
========================================

### 保存/导出木偶

1. 在编辑器中按 **Ctrl+S** 或点击保存按钮
2. 选择导出格式：
   - **Puppet文件 (仅JSON)** - 传统格式
   - **Puppet打包文件 (含图片)** ⭐推荐⭐
   - JSON格式
   - DragonBones格式
3. 选择保存位置
4. 完成！

### 加载木偶

1. 在编辑器中按 **Ctrl+O** 或点击加载按钮
2. 选择文件：
   - *.puppet - 打包文件（自动解压并加载）
   - *.json - JSON文件（需要图片在原位置）
3. 完成！

========================================
✨ 优势对比
========================================

| 特性 | JSON格式 | 打包格式 |
|------|---------|---------|
| 文件数量 | 多个（JSON + 图片） | 单个文件 |
| 分享便利性 | ❌ 需要打包所有文件 | ✅ 一个文件搞定 |
| 图片管理 | ❌ 需要手动管理路径 | ✅ 自动打包 |
| 跨平台 | ⚠️ 路径可能有问题 | ✅ 完全独立 |
| 文件大小 | 小（仅配置） | 中等（含图片，已压缩） |
| 适用场景 | 开发中 | 分享、发布 |

========================================
🔧 技术实现
========================================

### 核心类

1. **PuppetPackageIO.java**
   - 打包格式的核心实现
   - 使用ZIP格式打包
   - 自动收集和重映射纹理路径

2. **PuppetPackageExporter.java**
   - 导出器实现
   - 集成到导出系统

3. **ExportFormat.java**
   - 新增 PUPPET_PACKAGE 格式

4. **PuppetEditorApp.java**
   - 更新加载功能支持两种格式
   - 自动识别文件类型

### 工作流程

**保存时：**
1. 创建木偶配置
2. 收集所有纹理路径
3. 创建ZIP文件
4. 写入配置JSON
5. 复制所有纹理文件到ZIP
6. 重映射路径为打包内路径

**加载时：**
1. 检测文件扩展名
2. 如果是.puppet：
   - 解压到临时目录
   - 读取配置JSON
   - 重映射路径为临时文件路径
   - 应用配置
3. 如果是.json：
   - 直接加载配置
   - 使用原始路径

📝 使用示例

### 场景1：分享木偶给朋友

1. 在编辑器中创建木偶
2. 保存为 "my_character.puppet" (打包格式)

3. 所有资源自动加载 ✅

### 场景3：版本控制

开发中：
- 使用 JSON 格式
- 图片单独管理
- 便于Git追踪变更

发布时：
- 导出为 .puppet 格式
- 一个文件包含所有内容
- 方便分发

========================================
⚠️ 注意事项
========================================

1. **临时文件**
   - 加载.puppet文件时会解压到临时目录
   - 临时文件在程序退出时自动删除
   - 不要依赖临时文件路径

2. **文件大小**
   - 打包文件包含所有图片
   - 大小取决于纹理数量和质量
   - 已使用ZIP压缩

3. **兼容性**
   - .puppet文件是标准ZIP格式
   - 可以用解压软件打开查看
   - 向后兼容旧的JSON格式

4. **路径处理**
   - 自动处理绝对路径和相对路径
   - 打包时统一转换为相对路径
   - 加载时自动重映射

========================================
🐛 故障排除
========================================

**问题：保存时提示找不到纹理文件**
解决：确保所有纹理文件存在且路径正确

**问题：加载.puppet文件失败**
解决：
1. 检查文件是否完整
2. 尝试用解压软件打开查看
3. 查看控制台错误信息

**问题：加载后纹理显示不正确**
解决：
1. 检查临时目录权限
2. 确保有足够的磁盘空间
3. 重启编辑器重试
