## 使用骨骼分组功能

### 1. 创建骨骼组（新的对话框方式）

1. **加载或创建木偶**
   - 打开现有的 .puppet 文件，或创建新木偶

2. **打开分组控制面板**
   - 在编辑器UI中找到"组控制"面板（GroupControlPanel）

3. **点击"创建组"按钮**
   - 会弹出一个对话框，显示所有可用的骨骼

4. **在对话框中选择骨骼**
   - 点击骨骼名称前的复选框来选择/取消选择
   - ☐ = 未选中
   - ☑ = 已选中
   - 使用"全选"/"取消全选"按钮快速操作

5. **（可选）输入组名**
   - 在组名输入框中输入名称（如"头部组"）
   - 如果不输入，会自动生成名称（Group_1, Group_2...）

6. **点击"确定"**
   - 组会被创建，所有选中的骨骼会一次性添加到组中
   - 屏幕上会显示成功信息

### 2. 骨骼从旧组移动的反馈

**场景**: 如果你选择的骨骼已经属于其他组

**系统行为**:
- 骨骼会自动从旧组移除
- 添加到新组

**UI反馈示例**:
```
创建组成功: 头部组，已添加 3 个骨骼
以下骨骼已从旧组移除：
  - head (从 身体组)
  - eyes (从 面部组)
```

### 3. 旋转骨骼组

1. **选择组**
   - 在组列表中点击要旋转的组

2. **点击旋转按钮**
   - `← 90°` - 向左旋转90度（逆时针）
   - `↑ 180°` - 转身180度
   - `→ 90°` - 向右旋转90度（顺时针）

3. **观察效果**
   - 所有组成员的方向贴图会自动重映射
   - 例如：左转90°后，front贴图变成left，left贴图变成back...

### 4. 管理组成员

#### 添加单个骨骼到现有组
1. 在骨骼列表中选择一个骨骼
2. 在组列表中选择目标组
3. 点击"添加骨骼"按钮

**反馈示例**:
```
已添加 hand_left 到组 手臂组 (已从 身体组 移除)
```

#### 从组中移除骨骼
1. 选择要移除的骨骼
2. 点击"移除骨骼"按钮

**反馈示例**:
```
已从组 头部组 移除 head
```

### 5. 删除组

1. 在组列表中选择要删除的组
2. 点击"删除组"按钮
3. 组会被删除，所有成员骨骼的组关系会被清除

**反馈示例**:
```
删除组成功: 头部组
```

## 测试建议

### 基础测试
1. 创建一个简单的木偶（如头+身体+手臂）
2. 为每个部件设置多方向贴图（front, back, left, right）
3. 创建组（如"头部组"包含head和eyes）
4. 测试旋转，验证贴图重映射是否正确

### 组移动测试
1. 创建组A，添加骨骼1、2、3
2. 创建组B，在对话框中选择骨骼2、3、4
3. 确认反馈信息显示骨骼2和3从组A移除
4. 验证组A现在只包含骨骼1

### 持久化测试
1. 创建多个组
2. 保存木偶文件（.puppet）
3. 关闭并重新打开编辑器
4. 加载木偶文件
5. 验证所有组和成员关系正确恢复

## 常见问题

**Q: 对话框没有显示所有骨骼？**
A: 对话框当前限制显示最多可见的骨骼数量。如果骨骼太多，考虑添加滚动功能（未来改进）。

**Q: 能否让一个骨骼属于多个组？**
A: 当前设计不支持。一个骨骼只能属于一个组，这样可以避免旋转冲突。

**Q: 如何查看骨骼属于哪个组？**
A: 选择骨骼后，查看组控制面板的"当前选中组"区域，或尝试添加到组时会显示旧组信息。

**Q: 旋转后如何重置？**
A: 目前需要手动反向旋转。计划添加"重置旋转"按钮（未来改进）。
