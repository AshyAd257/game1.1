# 摄像机系统修正 - 实现效果说明

## 修正日期
2026-09-13

## 核心设计规则

### 1. 角色控制机制
```
角色朝向 (playerFacing) = 鼠标控制（移动时）
移动方向 = 相对角色当前朝向的 WASD 输入
摄像机 = 被动跟随工具
```

### 2. WASD 行为
- **W** = 向角色当前面朝方向前进
- **S** = 向角色当前面朝方向后退
- **A** = 向角色当前面朝方向的左侧横移
- **D** = 向角色当前面朝方向的右侧横移

**关键点**：WASD 永远相对**角色朝向**，不是相对摄像机

### 3. 鼠标行为分类

#### 静止时
- 鼠标移动 → **只转摄像机**，角色不转身
- 摄像机可以 360° 自由环绕角色
- 角色朝向保持不变

#### 移动时
- 鼠标左右移动 → **角色转身** (`playerFacing` 改变)
- 摄像机同步跟随角色转身（锁定在背后）
- WASD 的"前后左右"随着角色转身而改变

### 4. 摄像机自动归位

#### 触发时机
- 按下 **W/A/S/D** 任意移动键
- 按下 **R** 重置键

#### 归位行为
1. 摄像机平滑移动到**角色正后方**
2. 目标位置：`playerFacing + 180°`（相对角色）
3. 使用指数衰减平滑插值（不会突然跳转）
4. 归位速度：`CAMERA_ALIGN_SPEED = 10f`

#### 归位后状态
- 摄像机锁定在角色背后
- 摄像机朝向 = 角色朝向
- 移动时摄像机跟随角色移动和转身

## 技术实现细节

### 1. 角色朝向更新

```java
// 移动中：鼠标控制角色转身
if (isMoving) {
    playerFacing += mouseDelta;  // 更新角色朝向
    thirdPersonCamera.rotate(mouseDelta, 0);  // 摄像机同步
}

// 静止时：鼠标只转摄像机
else {
    thirdPersonCamera.rotate(mouseDelta, 0);  // 只转摄像机
    // playerFacing 不变
}
```

### 2. WASD 移动计算

```java
// 基于角色朝向计算方向
Vector3f forward = getPlayerFacingDirection();  // sin/cos(playerFacing)
Vector3f right = forward.cross(UNIT_Y);

// 组合输入
Vector3f movement = new Vector3f();
if (W) movement.add(forward);      // 角色前方
if (S) movement.add(-forward);     // 角色后方
if (A) movement.add(-right);       // 角色左侧
if (D) movement.add(right);        // 角色右侧
```

### 3. 摄像机自动归位

```java
// 按下 WASD 或 R 时触发
needsCameraAlign = true;

// 每帧更新
if (needsCameraAlign) {
    float targetYaw = playerFacing + PI;  // 角色背后
    float currentYaw = camera.getYaw();
    
    // 指数衰减平滑插值
    float diff = shortestAngleDiff(currentYaw, targetYaw);
    float t = 1 - exp(-ALIGN_SPEED * tpf);
    float newYaw = currentYaw + diff * t;
    
    camera.setYaw(newYaw);
    
    // 足够接近时完成归位
    if (abs(diff) < 0.01) {
        needsCameraAlign = false;
    }
}
```

### 4. 平滑插值算法

使用**指数衰减**而不是线性插值：

```
优点：
- 速度自适应（远时快，近时慢）
- 不会突然停止
- 感觉更自然
- 可以中途打断重新触发

公式：
t = 1 - e^(-speed * tpf)
newValue = currentValue + (target - current) * t
```

## 与之前实现的对比

### 之前的错误实现

```diff
- WASD 相对摄像机方向
- 删除了自动归位功能
- 移动方向会改变角色朝向
- R 键瞬间重置（无归位）
```

### 现在的正确实现

```diff
+ WASD 相对角色朝向
+ 按键触发自动归位
+ 角色朝向由鼠标控制（移动时）
+ R 键触发归位 + 重置距离
```

## 预期的用户体验

### ✅ 应该看到的效果

1. **静止观察**
   - 鼠标可以自由环绕角色 360°
   - 角色不会转身

2. **开始移动**
   - 按 WASD 任意键
   - 摄像机平滑移动到角色背后（约 0.2-0.5 秒）
   - 开始跟随移动

3. **移动中转向**
   - 鼠标左右移动
   - 角色转身
   - WASD 的"前后左右"跟着角色转

4. **R 键重置**
   - 摄像机归位到角色背后
   - 距离重置到默认值（8米）
   - 俯仰角重置到默认值（-20°）

### ❌ 不应该出现的问题

1. **摄像机突然跳转** → 如果出现，说明插值有问题
2. **角色走歪了** → 说明 WASD 计算有问题
3. **鼠标不起作用** → 检查 isMoving 判断
4. **摄像机不归位** → 检查 needsCameraAlign 触发

## 总结

这次修正实现了**正确的第三人称控制机制**：

✅ **角色自主性** - 角色有自己的朝向，不完全受摄像机控制

✅ **灵活的观察** - 静止时可以自由环绕
✅ **平滑的过渡** - 归位使用指数衰减，不会突兀
✅ **一致的行为** - WASD 和 R 键都触发归位
