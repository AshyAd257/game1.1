# 木偶编辑器：实体部件新模式

三维条带已接入，最新贴图约定与快捷视角见 [三维条带使用说明](STRIP3D_EDITOR.md)。

原先独立的新模式演示已替换为实体部件模式。它与传统编辑器共用骨骼、动画、关键帧、撤销记录、保存和导出逻辑；部件创建与控制界面使用新的实体／图像方案。旧模式仍可进入。

## 打开与操作

双击项目根目录 `launch-volume-editor.bat`，或在模式选择页选择「新模式 · 实体部件」。旧的 `launch-volume-workbench.bat` 也会打开这个新模式。

| 位置 | 操作 |
| --- | --- |
| 顶部「显示：模型／图像」 | 点击切换两种显示。模型显示圆柱、锥台、圆锥、方块；图像显示条带／贴图外观。同一套骨骼和动画驱动两种显示。 |
| 左侧「部件 → 新增部件」 | 弹窗选择类型、宽高深、顶部比例和像素密度。确定后挂在当前选中骨骼下，取消不创建。支持撤销／重做。 |
| 右侧「实体」 | 点击形状按钮直接修改；单击宽高深数值或“修改长宽高…”打开三项尺寸表单；顶部比例和像素密度仍可单击编辑。 |
| 右侧「姿态」 | 修改局部骨骼的 XYZ 位置、旋转角度、缩放。旋转修改的是骨骼本身，子部件会跟随。 |
| 右侧「图像」 | 直接导入上／中／下层 PNG，切换行列取样模式，点击“编辑行重要度（1–3）…”打开贴图直接逐行修改；法线在贴图设置中导入。 |
| 右侧「光照」 | 简易光照开关、水平角、仰角和强度。 |
| 左侧「动画」与底部时间轴 | 使用原有播放、关键帧、快照、复制粘贴关键帧、动画导入导出功能。 |
| 左侧下方「动画层／骨骼组」 | 展开原有动画层或骨骼组面板。点击「部件层级」回到部件列表。新模式建组弹窗支持滚动多选骨骼。 |
| 左侧「文件」 | 继续使用原有木偶加载、保存、追加、动画导入导出入口。 |

新部件默认启用条带系统，但不添加贴图；未导入图片时图像层保持透明，可切换模型显示编辑实体。新模式初始人偶用于示范空间关系，可删除或加载自己的木偶。

## 尺寸、像素与空间关系

宽、高、深按 1–4096 的整数艺术像素输入。世界尺寸 = 像素尺寸 ÷ 每世界单位像素数。

三维条带的源图尺寸由导入 PNG 确定；修改实体宽高改变图像的世界显示尺寸，不改变源图行列。深度和收尖比例用于空间参考实体。旧二维条带继续保留原来的选框尺寸联动。

模型／图像切换只改变显示，不改变骨骼的位置、父子关系或关键帧。模型用于观察和编辑空间关系，不会自动生成游戏碰撞体。

## 法线与光照

法线使用**部件局部坐标 XYZ**：RGB 的 0–255 对应 -1–1；局部 +Z 约为 RGB(128,128,255)。这与普通网格的切线空间法线贴图不同。法线随骨骼旋转，颜色与法线使用相同的 UV 和最近邻取样。

法线 PNG 尺寸应与颜色图一致。光照只有开关、水平角、仰角和强度；没有新增阴影系统。关闭光照时保留颜色图原有外观。

## 兼容与保存

默认 `.puppet` 完整文件保留实体参数、行权重、取样模式、骨骼姿态并打包三层颜色／法线图片，导入无需原图。旧 JSON `.puppet`、`.json` 和 `.ppkg` 仍可读取。复制、粘贴、镜像粘贴会携带实体与条带设置。加载旧木偶时，新模式为尚无实体设置的贴图部件添加参考实体，保留原有图片和骨骼数据；导入的真实网格仍保持原样。

旧模式保留原有工作台入口及旧部件工作流。模式本身不是一种新的互不兼容文件格式。

## 当前范围

已按更新版 HTML 接入三层条带、透视挑行／挑列、行重要度、各层法线与小键盘快捷视角。图像是面向相机的卡片，其深度为卡片平面深度。新部件默认使用三维条带；旧二维文件保持原样，可在右侧图像页开启三维条带。

仍未提供任意缩放下固定屏幕像素大小、游戏碰撞体、完整场景性能基准或编辑器内绘图工具。新模式的三维条带不再使用旧的每圈 36 列约束，而是以源图宽度作为中层完整周期。
