# 字体使用指南

## 概述

本项目使用自定义的 `TTFontLoader` 来渲染 TrueType 字体，支持中英文像素字体显示。

## 核心组件

### 1. TTFontLoader（字体加载器）

**位置：** `com.Hecate.ui.common.TTFontLoader`

**功能：**
- 加载 TTF 字体文件（支持系统字体和资源字体）
- 将字符渲染为纹理（使用 Java AWT）
- 天然支持 Unicode（中文、英文、符号等）
- 字符缓存机制（避免重复渲染）

**技术原理：**
```
TTF字体文件 → Java AWT Font → 逐字符渲染 → BufferedImage → JME Texture → Quad Geometry
```

### 2. TrueTypeTextUI（文本UI组件）

**位置：** `com.Hecate.ui.TrueTypeTextUI`

**功能：**
- 封装了 `TTFontLoader`，提供简单易用的 API
- 管理文本节点的生命周期
- 支持动态显示/隐藏文本

### 3. TextField（文本输入框）

**位置：** `com.Hecate.ui.common.TextField`

**功能：**
- 可编辑的文本输入框
- 支持键盘输入（中英文）
- 光标显示和闪烁效果
- 文本长度和宽度限制

## 使用方法

### 方法1：使用 TrueTypeTextUI（推荐用于简单文本显示）

```java
// 1. 创建 TrueTypeTextUI 实例
TrueTypeTextUI textUI = new TrueTypeTextUI(app);

// 2. 加载字体
textUI.loadFont("Interface/Fonts/ZLabsBitmap_12px_CN（简体中文）.ttf", 48);

// 3. 显示文本
textUI.showText("欢迎！", ColorRGBA.White, x, y);

// 4. 隐藏文本
textUI.hideText();

// 5. 清理资源
textUI.cleanup();
```

**示例：** 见 `WelcomeScreen.java`

---

### 方法2：直接使用 TTFontLoader（推荐用于复杂场景）

```java
// 1. 加载字体
TTFontLoader fontLoader = TTFontLoader.loadFontFromResource(
    assetManager,
    "Interface/Fonts/ZLabsBitmap_12px_CN（简体中文）.ttf",
    30f  // 字体大小
);

// 2. 创建文本节点
Node textNode = fontLoader.createText("你好世界", ColorRGBA.White);
textNode.setLocalTranslation(x, y, 1000);

// 3. 添加到场景
app.getGuiNode().attachChild(textNode);

// 4. 计算文本宽度（用于居中对齐等）
float textWidth = fontLoader.getTextWidth("你好世界");
```

**示例：** 见 `InventoryUI.java` 的搜索框实现

### 方法3：使用 TextField（推荐用于文本输入）

```java
// 1. 加载字体
TTFontLoader fontLoader = TTFontLoader.loadFontFromResource(
    assetManager,
    "Interface/Fonts/ZLabsBitmap_12px_CN（简体中文）.ttf",
    30f
);

// 2. 创建 TextField
TextField textField = new TextField(
    app,
    fontLoader,
    "",              // 初始文本
    x, y,            // 位置

);

// 3. 配置样式
textField.setTextColor(ColorRGBA.White);
textField.setBackgroundColor(new ColorRGBA(0, 0, 0, 0)); // 透明背景
textField.setMaxWidth(200);  // 最大宽度
textField.setMaxLength(50);  // 最大字符数

// 4. 添加到场景
app.getGuiNode().attachChild(textField.getRootNode());

// 5. 激活输入
textField.setFocused(true);

// 6. 监听文本变化
textField.setTextChangeListener(newText -> {
    System.out.println("输入的文本：" + newText);
});

// 7. 每帧更新（用于光标闪烁）
public void update(float tpf) {
    textField.update(tpf);
}

// 8. 清理资源
textField.cleanup();
```

**示例：** 见 `InventoryUI.java` 的制造界面搜索框

2. 使用 `TTFontLoader.loadFontFromResource()` 加载
3. 确保字体文件包含所需的字符集（中文字体需包含汉字）

## 像素字体专用设置

为了保持像素字体的清晰锐利效果，需要使用**最近邻过滤**：

```java
// 对于UI背景纹理
texture.setMagFilter(Texture.MagFilter.Nearest);
texture.setMinFilter(Texture.MinFilter.NearestNoMipMaps);
```

TTFontLoader 内部已自动对字符纹理使用双线性过滤（`Bilinear`），这样可以让字体边缘平滑，同时保持像素风格。

## 常见问题

### Q1: 字体显示乱码或方框？
**A:** 检查字体文件是否包含对应的字符。中文字符需要使用包含中文字形的字体。

### Q2: 字体模糊不清？
**A:** 
- 检查字体大小是否合适（太小会模糊）
- 像素字体建议使用 12、24、36、48 等 12 的倍数
- 确保 Z 坐标设置正确（避免被其他元素遮挡）

### Q3: 性能问题？
**A:** 
- TTFontLoader 内部有字符缓存，相同字符不会重复渲染
- 避免频繁创建/销毁文本节点，尽量复用
- 长文本可以考虑分段显示

### Q4: 如何实现文本居中？
**A:**
```java
String text = "居中文本";
float textWidth = fontLoader.getTextWidth(text);
float x = (screenWidth - textWidth) / 2;
float y = screenHeight / 2;
textNode.setLocalTranslation(x, y, 1000);
```

### Q5: 如何实现换行？
**A:**
```java
String text = "第一行\n第二行\n第三行";
Node textNode = fontLoader.createText(text, ColorRGBA.White);
```
TTFontLoader 自动处理 `\n` 换行符。

## 技术细节

### 字符渲染流程

1. **加载字体**：使用 `Font.createFont()` 加载 TTF 文件
2. **字符测量**：使用 `FontMetrics` 测量字符尺寸
3. **渲染到图像**：使用 `Graphics2D` 将字符绘制到 `BufferedImage`
4. **垂直翻转**：修正 OpenGL Y 轴方向
5. **转换为纹理**：将 RGBA 像素数据转换为 JME `Texture2D`
6. **创建几何体**：使用 `Quad` + `Unshaded` 材质显示字符

### 坐标系说明

```
JME GUI 坐标系：
- 原点 (0, 0) 在屏幕左下角
- X 轴：向右为正
- Y 轴：向上为正
- Z 轴：值越大越靠前（1000+ 确保在最上层）
```

### 字符缓存机制

```java
private Map<Character, CharInfo> charCache = new HashMap<>();
```

每个字符只渲染一次，后续使用从缓存中读取，大幅提升性能。

## 对比：TTFontLoader vs jme-ttf 库

| 特性 | TTFontLoader（当前方案） | jme-ttf 库 |
|------|------------------------|-----------|
| **依赖** | 仅 Java AWT + jME | 需要外部库 |
| **中文支持** | 天然支持（AWT） | 需要特殊配置 |
| **实现难度** | 简单直观 | API 复杂 |
| **性能** | 中等（纹理缓存） | 高（mesh 渲染） |
| **像素字体** | 完美支持 | 需要调整 |
| **维护成本** | 低（100行代码） | 高（第三方依赖） |

**结论：** TTFontLoader 更适合本项目的像素风格游戏UI。

## 最佳实践

1. **字体大小选择**
   - UI 标题：48-72px
   - 正文：24-36px
   - 小字：12-18px

2. **颜色选择**
   - 亮色背景：使用深色文字（`ColorRGBA.Black`）
   - 暗色背景：使用亮色文字（`ColorRGBA.White`）

3. **性能优化**
   - 静态文本：创建一次，复用节点
   - 动态文本：使用 `setText()` 更新，而非重新创建

4. **资源管理**
   - 不再使用的文本节点及时 `removeFromParent()`
   - 长时间不用的字体可以清空缓存
